# 数据管理计划（DMP）摘要

## 1. 数据类别

| 类别 | 内容 | 敏感级 |
|------|------|--------|
| A | 选项答卷、性别/年龄段 | 中（健康相关自陈） |
| B | 时长、修改次数、批次 ID | 低–中 |
| C | IP/UA 的 HMAC 哈希、会话指纹 | 低（不可逆，仍按准标识符管理） |
| D | 人工质量标签、模型分数 | 低 |
| E | 合成注入答卷（标记 isSynthetic） | 低（实验数据） |

## 2. 存储与备份

- 生产库：MongoDB（【Atlas / 本地 / 校园云】）  
- 研究导出：`AI_SCI/data/raw/`（不入库公开 Git）  
- 备份：每周导出 JSON 至加密移动硬盘或学校网盘【路径】  
- 密钥：`SESSION_SECRET` / `QUALITY_HASH_SECRET` 仅存环境变量，不进代码仓库  

## 3. 访问控制

| 角色 | 权限 |
|------|------|
| 普通填写者 | 提交本人答卷 |
| 评估创建者 | 查看/导出/标注自己的评估 |
| 课题负责人 | 全部研究导出与模型训练 |

## 4. 共享与发表

- 论文：汇总表、指标、必要时脱敏特征统计  
- 开源：可公开检测脚本与**不含真实答卷**的 demo 数据  
- 若审稿人要求数据：提供合成污染协议 + 汇总统计；真人逐条数据需在伦理允许范围内单独申请  

## 5. 保留与销毁

- 保留至【项目结束 + 3 年】或学校规定  
- 销毁：删除 Mongo 集合与导出副本，记录销毁日期  
- 账号注销/删除评估：级联删除答卷（系统已实现）  

## 6. 事件响应

疑似泄露：立即轮换 `QUALITY_HASH_SECRET` 与数据库密码，停止公网暴露，报告【学校信息安全/导师】，评估哈希是否足以降低风险。
